Blackout V3: OSC & MIDI

🔬 Undersøgelse · 30. oktober 2026 · Hoved #73 · ← dashboard
💡 Kort sagt: Ja. Blackout V3 (udkom 7. okt 2026, nu v3.0.3) er en helt ny app, og OSC/MIDI er markant bedre end i V2/Next: fuld OSC-kommandoreference med /blk/…-adresser, Learn Mode der mapper både MIDI og OSC ved at trykke på kontrollen, netværks-MIDI, motoriseret fader-feedback, MTC-timecode og native Stream Deck. OSC-output er dog stadig kun fader-bevægelser, og TCP er "in development".

Overblik

V3 er en separat app på App Store (ikke en opdatering af Blackout Next — Next er officielt "legacy"/V2-beta). Kræver iPadOS 18+, abonnement fra $24,99/md. (Core/Pro/Command-tiers, 2 ugers gratis prøve, trade-in-tilbud til V2-folk). Udgivelsestempo lige nu: 3.0.0 → 3.0.3 på to uger.

OSC i V3

  • OSC 1.1 over UDP (TCP er på vej). Ind: port 9999 · ud: port 8888, flere navngivne forbindelser med tænd/sluk.
  • Fuld kommandoreference — alt kan rammes direkte: /blk/fader/global/1/level (0-255), keys/actions (float 0/1), encodere (float ±4), macros, grupper, effekter, favoritter, LivePlot, view states og sideskift.
  • Learn Mode tager OSC: tænd Learn, tryk på kontrollen i Blackout, send en OSC-kommando — færdig. Mapping-presets kan gemmes/deles.
  • OSC-timecode: /blackout/tc med "HH:MM:SS:FF" — kan drive timecode-triggers.
  • Begrænsning: OSC-output er kun fader-bevægelser (knapper er envejs).

MIDI i V3

  • USB-C, Bluetooth og netværks-bridge — auto-reconnect ("When Last Connected" som standard).
  • Learn Mode (hed "MIDI Learn" før): tryk på kontrollen, rør hardwaren. Global (følger slot) eller Local (følger objekt) mapping.
  • Rigtige encoder-modes: Absolute, Relative (2s Complement / Offset 64 / Sign Bit / Raw Delta) og Cycling — endeløse encodere virker endelig ordentligt.
  • Motoriserede fadere: Blackout sender niveauer tilbage til hardwaren.
  • MTC-timecode ind fra enhver MIDI-enhed, framerate læses af signalet; timecode- og DMX-triggers kan affyre cues (stemples live med "+ Trigger").
  • 3.0.3 fiksede: hardware-taster affyrer ikke MIDI-actions mens man skriver i et felt; MIDI Learn på Stream Deck-taster kan nu erstatte/køre/annullere.
